# Fundamentos da Engenharia de IA

Estado e registros da minha formação em Engenharia de IA, conduzida com o tutor (ai-tutor).

- `curriculum.md`: currículo e módulos
- `session-log.md`: registro das sessões
- `lessons/`: aulas
- `projects/`: código praticado em cada módulo
- `flashcards.md` e `.ai-tutor/`: estado do tutor (revisão espaçada, progresso, fontes)

As chaves de API são lidas do ambiente (`OPENAI_API_KEY`) e nunca são versionadas.
